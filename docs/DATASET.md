# Dataset and model-data notes

## Selected dataset

TruthLens uses the **LIAR benchmark dataset** by William Yang Wang, introduced
in *"Liar, Liar Pants on Fire": A New Benchmark Dataset for Fake News Detection*
(ACL 2017). Its official download and accompanying README are at
<https://sites.cs.ucsb.edu/~william/data/liar_dataset.zip>.

The dataset README says it is available **for research purposes only**, is
provided as-is, has no guarantees, and that original sources retain copyright.
Use it only for non-commercial research/education in line with those terms.
This project does not redistribute its contents; dataset files and trained
artifacts are excluded from version control. Review the current source terms
before any public or commercial deployment.

## Data preparation

`backend/scripts/prepare_dataset.py` downloads the source archive, preserves the
provided train/validation/test partitions, retains only rows with the expected
14-column format and one of the six documented labels, and writes statement
text and labels to `data/liar/liar_processed.csv`. Two malformed rows in the
provided training file are skipped. The model uses statement text only; speaker
metadata and historical truth-count fields are excluded to avoid obvious
metadata leakage.

## Label interpretation and limitations

The labels are the dataset's attributed benchmark ratings (`pants-fire`,
`false`, `barely-true`, `half-true`, `mostly-true`, `true`), not objective
ground truth generated by this project. They are political statements from one
fact-checking source and one historical period, so the data has domain,
selection, and temporal biases. A model prediction is not a verdict about a
new article. Independent evidence and cited sources must be considered
separately.

## Reproducible commands

From the project root in PowerShell:

```powershell
.\.venv\Scripts\python.exe backend\scripts\prepare_dataset.py
.\.venv\Scripts\python.exe backend\scripts\train_baseline.py
```

Metrics are saved locally to `backend/models/liar_tfidf_metrics.json`; the
serialized model is local to `backend/models/liar_tfidf_logreg.joblib`.
